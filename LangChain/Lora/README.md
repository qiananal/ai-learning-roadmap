# 🧭 一、 通俗易懂聊原理：LoRA 到底是怎么降维打击的？

大模型（比如 LLaMA 3、Qwen）之所以聪明，是因为它的内部有几百层、上百亿个权重参数（在数学上就是巨大的矩阵 $W_0$）。

## 🚨 传统的全量微调（Full Fine-Tuning）

假设大模型的一层网络是一个 $4096 \times 4096$ 的大矩阵。全量微调意味着：显卡在训练时，必须把这 $4096 \times 4096 \approx 16,770,000$（一千六百万）个参数全部计算出梯度、全部在显存里更新一遍。

这仅仅是大模型其中一层的参数量！全模型算下来，你的显存直接当场吐血崩溃。

## 💡 LoRA 的天才解法：低秩分解（Low-Rank Adaptation）

微软的科学家发现：大模型在全量微调时，这一一千六百万个参数虽然都在变，但其实绝大部分参数变动的方向是高度一致、极其冗余的。也就是说，它本质上的有效变化，根本不需要这么大的矩阵来承载！

于是，LoRA 提出了一个震动整个 AI 界的公式：$$W = W_0 + \Delta W$$

其中：$W_0$ 是原本大模型的一千六百万参数。

LoRA 进场第一件事：全部锁死（Freeze），不准动！ 这样它们在显卡里就不需要计算梯度，显存直接省下来 90%！

$\Delta W$ 是我们希望大模型改变的“新脑回路”。那怎么让这个 $\Delta W$ 变得极小呢？LoRA 动用了数学里的矩阵低秩分解。它把这个 $4096 \times 4096$ 的巨型变化矩阵，拆成了两个首尾相连的瘦子矩阵 $A$ 和 $B$ 相乘：$$\Delta W = B \times A$$矩阵 $A$ 的形状是：$4096 \times r$矩阵 $B$ 的形状是：$r \times 4096$这里的 $r$ 就是传说中的“秩（Rank）”，通常大厂在微调时，这个 $r$ 只设置为 $8$ 或者 $16$。

📊 惊人的数学账本：如果 $r = 8$：矩阵 $A$ 的参数量：$4096 \times 8 = 32,768$矩阵 $B$ 的参数量：$8 \times 4096 = 32,768$两个小矩阵的总参数量：$32,768 + 32,768 = 65,536$（六万）！

兄弟！你看明白了没有？！原本需要显卡死磕更新的 16,770,000（一千六百万） 个参数，被 LoRA 这么一拆，变成了只需要更新 65,536（六万） 个参数！参数量直接暴跌了 250 倍！ 这就是为什么你用实验室的一张普通消费级显卡（如 4090），就能轻松给百亿大模型“物理洗脑”的根本底层原因！
